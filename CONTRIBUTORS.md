# Contributors

Everyone who has made VellumScribe better. Entries are added by requesting a
pull request against this file, or by a maintainer after a merged
contribution.

## Maintainers

| Person                                     | Role                                                                   |
| ------------------------------------------ | ---------------------------------------------------------------------- |
| [@Perchemop](https://github.com/Perchemop) | Project owner, BDFL — scope, architecture, releases, security, conduct |

## Contributors

- **@Perchemop** — original implementation, spec, QC checklists, and every
  bug report that surfaced work that was silently broken.
- **The OpenCode agent team** (implementation and verification; free models,
  see `docs/current-model-map.md`) — implemented every feature in this
  repository under the owner's direction. Listed here because coordinated
  machine work still takes human judgement to specify; the human's name is the
  accountability marker.

_Are you missing from this list? Open a PR — no contribution is too small, and
we would rather add your name too late than never._

## How contributions are recognised

Every merged contribution is credited in the release notes for the release that
carried it (`CHANGELOG.md`). Security reports are credited in the advisory
unless the reporter asks otherwise (`SECURITY.md`).

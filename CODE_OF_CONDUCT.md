# Code of Conduct

## Our commitment

We want everyone who interacts with VellumScribe — filing issues, reviewing
code, asking questions, or chatting — to be able to do so without hostility.
This project is built and maintained by a small team with limited time; we
spend that time best when nobody has to defend themselves to participate.

## Expected behaviour

- Be kind, direct, and technical. Critique the code, never the person.
- Assume good faith: most friction here is a misunderstanding, not malice.
- Prefer public threads (issues and PRs) so answers help the next person.
- Say what you actually mean, and accept clarification questions gratefully.
- Disagree by offering evidence — a failing case, a log, a doc link.

## Unacceptable behaviour

- Insults, harassment, discriminatory jokes or imagery, or personal attacks.
- Publishing another participant's private information without consent.
- Deliberate disruption: thread hijacking, sealioning, repeated relitigating of
  settled decisions.
- Sexualised language or attention of any kind.
- Any behaviour that would get someone shown the door at a workplace.

## Scope

This conduct standard applies to every project space: this repository, its
issues and pull requests, and any channel the project officially points at. A
person who cannot behave elsewhere under this project's banner is still subject
to it here.

## Enforcement

Violations are handled by the project maintainers (see `GOVERNANCE.md`).
Consequences scale with severity and repetition: a warning → temporary
suspension from project spaces → permanent ban. We decide cases individually
and explain our decision where we can do so without exposing reporters.

## Reporting

- **Conduct violations:** contact the maintainer privately via GitHub
  (`@Perchemop`) — click the profile → "..." → Message, or use any contact
  address published in `GOVERNANCE.md`. All reports are confidential.
- **Security reports have their own path** — see `SECURITY.md`. Never post
  vulnerability details to a public issue.

Reports are reviewed within **7 days**. If you get no reply in that window and
believe the report is serious, open a GitHub issue saying only that you have a
conduct report pending — do not include its content.

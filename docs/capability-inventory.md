# Capability Inventory

Per guide §II.27.3: the single source of truth for what VellumScribe is
designed to do. A capability absent from this table can be neither claimed
done nor reported missing. Implementation evidence (test name, CI run) lives
in `docs/parity.md`; readiness percentages move only from verified evidence.

Status values: **not started / partial / implemented / out of scope**.

**Source column convention (clean-room, §II.27.2):**

- `original` — the capability is VellumScribe's own design; the authority is
  this project's own spec (`docs/scope.md`), not any other product.
- `inspiration` — the behaviour was observed in a product named in
  `docs/inspiration.md`, from public sources only; the URL is recorded.
- `standard` — a public standard or open specification defines the behaviour.

This inventory was first enumerated 2026-10-28 from `docs/scope.md`
(owner-confirmed 2026-10-21) and `docs/parity.md`; it is not retro-fitted
from code. Anything the app does that is not listed here must be added or
removed by a scope decision (§II.27.3: never silently).

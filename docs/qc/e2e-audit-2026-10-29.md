Scope: the whole application (functional behaviour, data integrity, quality
gates) **and** the GUI/design surface. Method: code-path tracing in this
repository plus the rendered-evidence review recorded in
`docs/design/audit-2026-10-28-gui.md`. Every finding below was **verified by
reading the code path**, not taken from a summary.

Environment limits (honest): no on-device Android run in this audit; native
Whisper inference, real cloud round-trips, and hardware focus/contrast remain
**unverified** (see §6).

## 4.1 Remediation updates (2026-10-29, later the same day)

- **M-1** palette unification: TranscriptViewer migrated to zinc (101 tokens).
- **M-4** partial: attach/more sheets close on Escape and declare `aria-modal`;
  the checklist delete button is named and focusable. Focus containment inside
  dialogs is still open.
- **M-5** metrics toggle focus ring; **M-6** real keyframes (`vs-fade-in`,
  `vs-slide-up`) under the global reduced-motion layer; **M-7** placeholder
  contrast (editor, list, archive).
- **S-4 (new, serious — found by rendered evidence)**: the theme toggle was a
  dead control. Tailwind v4 defaults `dark:` to the OS media query, silently
  ignoring the app's `.dark` class; a dark capture rendered light. Fixed with
  `@custom-variant dark (&:where(.dark, .dark *))`, and the dark visual capture
  now asserts the dark palette programmatically.
- **Capability tests added** (`src/lib/capabilityCoverage.test.ts`, 6 tests):
  metrics are local-only with zero network dispatch and no content leakage
  (CAP-023); version snapshots persist, carry checksums and prune (CAP-007);
  the BYOK gate never sends a request without consent (CAP-020). 28 test files
  green on `main`.
- **CAP-021 note**: signing is enforced by the release workflow (tagged
  releases fail without the keystore) — that gate, not a unit test, is the
  honest proof for a build-machine property.
- **Process incident**: during the §II.29.4 purge, a stale mirror force-push
  briefly reverted PRs #119/#120 from `main`; both were recovered intact from
  the immutable `refs/pull` refs. Lesson in `docs/process-feedback.md` entry 3.
